# Evaluation Artifacts

Generated benchmark records, screenshots, model outputs, and phase reports are intentionally not tracked in the product repository.

Use this directory only as a local output location while running private evaluation work. Before publishing or committing any legal-quality result, follow `docs/operations/LEGAL_VALIDATION_PROTOCOL.md` and preserve the reviewer ledger outside the application source tree.

Do not commit:

- generated benchmark JSON, JSONL, or CSV files
- browser screenshots or local Chrome profiles
- ad hoc debug scripts
- model outputs
- internal accuracy reports that have not been externally reviewed
