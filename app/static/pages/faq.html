Short answers for teams evaluating Nyaya Darshana for research support, Vault document work, and Nyaya Ops matter workflows.

Product and legal review

Is this legal advice?

No. Nyaya Darshana is research and workflow software. It can retrieve sources, summarize documents, and structure work, but legal conclusions require independent professional review.

What does "source-grounded" mean?

Answers are designed to cite retrieved statutory or document evidence where available. A cited source still needs human review for currency, applicability, facts, and legal strategy.

Can the system verify eCourts or India Code pages live?

Only when the source allows access. If a source blocks automated access or requires CAPTCHA, the system records that human action is required and keeps provenance unverified.

Vault

Are Vault documents public?

No. Vault operations are scoped to the authenticated workspace and organization ID. Public SEO files do not expose private document URLs.

What file type is supported?

The launch upload flow accepts PDFs up to the displayed limit and validates file type before upload.

Nyaya Ops

What are human-action tasks?

They are workspace tasks created when ingestion hits a boundary such as CAPTCHA, source blocking, or manual court selection. They preserve audit evidence without bypassing access controls.

Which tenant is used by browser checks?

Authenticated API ingestion uses the active organization ID. Standalone browser checks use NYAYA_BROWSER_CHECK_TENANT_ID when set, otherwise default_tenant.
